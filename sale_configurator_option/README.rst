Changelog

18.0.1.0.0 (2025-11-22)
-----------------------

- **[MIGRATION]** Migration to Odoo 18.0.

|                                 | ⚠️ ``product_tmpl_id``            | ``configurable_product_tmpl_id``          |
+---------------------------------+-----------------------------------+-------------------------------------------+
|                                 | ``option_product_tmpl_id``        | ``product_tmpl_id`` ⚠️                    |
+---------------------------------+-----------------------------------+-------------------------------------------+

+---------------------------------+-----------------------------------+-------------------------------------------+

+---------------------------------+-----------------------------------+-------------------------------------------+
