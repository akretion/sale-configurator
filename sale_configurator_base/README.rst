This module is the technical base for the Sales Configurator modules
(such as ``sale_configurator_option`` or ``sale_configurator_variant``)

It provides the structure for managing configurable products within Odoo
Sales Orders, like the Parent/Child hierachy and the configuration
interface in the Sale Order Lines.
